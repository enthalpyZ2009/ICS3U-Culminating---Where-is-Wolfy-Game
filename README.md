# Where Is Wolfy? — ICS3U Culminating Project

A hide-and-seek game built in Java using Swing for my Grade 11 Computer Science (ICS3U) culminating project.

## Overview
Where's Wolfy? is a grid-based game where you have to find a hidden wolf using clues about how close you are to him. The goal is to catch Wolfy in as few steps and as little time as possible.

Once you find Wolfy, you must beat him in Rock, Paper, Scissors to win. If you lose, Wolfy escapes and you have to find him again!

## Features

Three difficulty levels: Easy (10×10), Medium (12×12), and Hard (15×15).

Get clues like "Cold," "Getting warmer," and "Very hot" as you search for Wolfy.

On Hard mode, Wolfy can move around the grid.

Obstacles: Avoid walls, blocked paths, and bombs.

Rock, Paper, Scissors: Challenge Wolfy after finding him to win the game.

Leaderboard: Saves player scores based on steps taken and completion time.

## How to Play

Use W, A, S, D to move around the grid.

## How to Run

1. Clone or download this repository.

2. Open the project in a Java IDE.

3. Run WheresWolfy.java to start playing.
